# Rizal Portfolio — React

Portfolio homepage built with React, TypeScript, Vite, Tailwind CSS, Motion, and Lucide React.

## Run locally (Windows PowerShell)

```powershell
cd path\to\rizal-portfolio-react
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```powershell
npm run build
npm run preview
```

## Customize before publishing

- Replace `hello@example.com` in `src/App.tsx` with your real email.
- Update GitHub and LinkedIn URLs in `src/App.tsx`.
- Verify experience titles, dates, and descriptions.
- Replace the conceptual project UI previews in `src/components/ProjectVisual.tsx` with genuine screenshots when available.
- Add a CV PDF and connect the download action.
- Add project case study routes when content is ready.

Theme preference is stored in `localStorage` (`portfolio-theme`) and the initial mode follows the system preference.
